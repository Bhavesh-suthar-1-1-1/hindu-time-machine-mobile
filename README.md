# The Hindu Time Machine — Mobile-friendly version

A phone-friendly copy of **[The Hindu Time Machine](https://timeline.tryambakmedia.in/)** — 1,989 moments of Sanātana Dharma on one wheel of time.

**Original site by [Manik Rege](https://www.instagram.com/manikthinks/) ([@manikthinks](https://www.instagram.com/manikthinks/)), [Tryambak Media](https://www.tryambakmedia.in).**

## What changed

The original site only works on a computer — on phones it shows a "open this on a computer" popup. This copy removes that block and stacks the page (header / wheel / event list / detail panel / era bar) so it scrolls like a normal website on a phone. All 1,989 events, text, colours, search, sound and the desktop layout are untouched.

Live site: https://bhavesh-suthar-1-1-1.github.io/hindu-time-machine-mobile/
